# 暗潮 · 靈寵修行

豎屏可玩垂直切片：**掛機升階 → 契約靈寵 → 秘境掉落**。

## 一週目標循環

```
契壇掛機 → 突破階段 → 契約最多 3 靈寵 → 秘境戰鬥掉落 → 靈紋強化
```

戰鬥編成：**1 御靈師人物 + 最多 3 靈寵**（已取代門徒）。

## 靈寵數值

每隻靈寵由三層資料合成最終攻／血／速：

| 層 | 例子 | 作用 |
|----|------|------|
| 種類 `SPECIES` | 礁狐／苔背／灰翼… | 基礎數值骨架 |
| 元素 `ELEMENTS` | 潮／岩／焰／嵐／幽 | 微調攻血速 |
| 性格 `PERSONALITIES` | 烈性／沉穩／狡黠… | 再加減成 |

實例上掛有 `genes`，**繁殖／交配後開**（`tryBreed` 已預留接口）。

## 技術棧

繼續用本 PWA（HTML/CSS/JS），唔使換引擎。
