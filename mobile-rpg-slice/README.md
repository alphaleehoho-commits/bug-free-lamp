# 暗潮 · 靈寵修行

豎屏可玩垂直切片：**掛機升階 → 秘境遇寵 → 機率契約 → 掉落**。

## 一週目標循環

```
契壇掛機 → 突破階段 → 秘境遇寵 → 契約入牧場 → 派出戰 → 升級／融合 → 靈紋強化
```

- 出戰：**1 人物 + 最多 3 靈寵**（可先獨自打本）
- 牧場：契約成功先入牧場；容量隨階段提升（初契 3 → 潮主 13）
- 遇見：打本後隨機；**待契約最多 5**，滿額唔會再新遇
- 契約：自選嘗試，耗靈石，按性格機率成功／逃脫
- 養成：升級（獨立、只跟自身等級）；同種族融合最高 3 階（主體 Lv10/20/30，隻數 2→4→8，繼承主體等級）

## 靈寵分類（而家）

| 維度 | 內容 |
|------|------|
| **種類 kind** | 獸、鱗、禽、甲、蟲 — 各綁一隻種族技能 |
| **種族 species** | 礁狐、潮鯉、灰翼、苔背、夜蛾、熒鰭 |
| **元素** | 潮／岩／焰／嵐／幽 |
| **性格** | 烈性／沉穩／狡黠／溫馴／狂放 |

### 技能

- **人物**：契印斬（初契）→ 潮霧庇護（通靈初期）→ 暗潮令旗（御靈）
- **靈寵**：獸撲襲、鱗潮濺、禽嵐擊、甲甲盾、蟲蝕咬

## 靈寵數值

每隻靈寵由三層資料合成最終攻／血／速：

| 層 | 例子 | 作用 |
|----|------|------|
| 種類 `SPECIES` | 礁狐／苔背／灰翼… | 基礎數值骨架 |
| 元素 `ELEMENTS` | 潮／岩／焰／嵐／幽 | 微調攻血速 |
| 性格 `PERSONALITIES` | 烈性／沉穩／狡黠… | 再加減成 |

實例上掛有 `genes`，**繁殖／交配後開**（`tryBreed` 已預留接口）。
