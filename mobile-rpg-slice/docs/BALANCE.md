# 平衡設計原則

本文件鎖定能力分工、稀有血統、兌換上限與節奏。實作以 `js/data.js` / `js/engine.js` 為準。

## 能力三軸

| 軸 | 角色 | 實作 |
|----|------|------|
| **稀有度** | 初始白板 | `RARITY.mult`：`1 / 1.18 / 1.38 / 1.65` |
| **代數** | 等級成長斜率 | `levelStatGains(gen)`：`+2/+6/+1 × (1 + gen×0.1)`；出戰 `genCombatMult` 僅留 `1 / 1.01 / 1.02 / 1.03` |
| **融合** | 出戰乘區 | 吸收改細（階 14%/19%/24%）；`fusionCombatMult` 階1/2/3 → `×1.06 / 1.12 / 1.20`，寫入 `fusionPowerMult` |

出戰概算：`(初始×稀有 + 等級成長累積) × 融合乘區 × 淵核／外觀／圖鑑等`

## 稀有重要性（唔硬鎖融合同稀有）

1. **拉闊初始倍率**（上表）
2. **繁殖優勢**：高稀有父母 → 仔稀有更易往上、高代數機率↑、元素／血脈變異↑、繁殖 CD 略減（`rarityBreedCdMult`）
3. **融合軟綁**：素材均稀有 ≥ 主體 → 全額；低 1 階 → ×0.8；再低 → ×0.55（仍可融）

## 兌換誠實 + 淵砂 sink

- 牧場欄柵／暖巢箋達 `RANCH_CAP_BONUS_MAX`（+12）／`HATCH_SLOT_BONUS_MAX`（+3）→ 精魂商肆灰掉＋購買攔截
- 淵砂長期 sink：**淵核**（`ABYSS_POWER_NODE_*`，最多 8，每級全隊攻擊 +1%）
- 潮淵高階蛋維持週限；成本 `ABYSS_EGG_COST = 110`

## 主線／掛機分池

- 主線深層（`tide_5+`）：難度 `1.26^extra`；首通加 `seal_ember`／靈石（掛機唔出）
- 掛機：潮露／飼料／珊瑚等 bulk
- 潮淵：週期挑戰定位，唔係一日清空永久池

## 蛋節奏

- `eggHatchMsFor`：`tierHatch × (1 + eggGen × 0.25)`（繁殖蛋帶代數）
- 商人／潮淵 A 蛋維持高階時長，成本匹配價值

## 變更時注意

改倍率後請跑 `node js/smoke-test.mjs`，並 bump `APP_BUILD` + `sw.js` cache。
