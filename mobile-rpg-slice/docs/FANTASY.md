# 放置幻想北星

> 2026-09 重定。實作以 `js/data.js` / `js/engine.js` / `js/ui.js` 為準。

## 一句話

**打開 GAME：睇住漂路小戰鬥同材料彈出；主動玩秘境係為解鎖新品種同搶稀有蛋；長遠爽感喺繁殖血脈。**

## 各系統角色

| 系統 | 角色 | 唔再係 |
|------|------|--------|
| 練功掛機 | 劇場（打交＋收穫動畫）＋日常素材／推章 | 唯一變強理由 |
| 秘境 | 品種閘門＋稀有以上蛋線 | 同掛機一樣嘅石／露 farm |
| 繁殖 | 長遠成長主軸（代數／稀有／雜交） | 可選側枝 |
| 進階（體階突破） | **已廢止**（存檔 `realm` 僅相容） | 內容閘門 |
| 深潛 | **暫凍**——後期再檢視，唔搶早期節奏 | 現階段主循環 |

## 玩家循環

1. 育成練功：睇自動戰鬥，材料飛入；露珠／階石餵等級。
2. 秘境：每日／主動打，解鎖品種、機率稀有以上蛋。
3. 孵化 → 水母池 → 繁殖：血脈抬天花板。
4. 更強出戰 → 更深漂路 → 更好掛機階梯。

## 秘境獎池規則

- **品種解鎖**：首通或遭遇解鎖野生種；未解鎖種圖鑑顯示「潮霧中」，唔出現喺繁殖／商肆野生池。
- **稀有以上蛋**：秘境通關／掃蕩有機率；掛機 AFK **唔出**稀有以上蛋。
- 普通素材以掛機為主；秘境石／露可低於掛機等效，避免「打完同掛機一樣」。

## 進階廢止

- UI 隱藏「育成 → 進階」；`tryBreakthrough` 對玩家關閉。
- 內容開閘改跟 **漂路章通關**（`spineStageFromState`）與 **品種解鎖表**，唔再靠共鳴突破。
- `state.realm`／共鳴可靜默保留（舊存檔），唔再當主目標。

## 深潛暫凍

- 入口可留，標「後期開放／暫不平衡」。
- 解鎖門檻維持高章或再抬；唔刪 code。
